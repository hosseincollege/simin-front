# فرانت سیمین

فرانت اصلی پروژه با Angular پیاده‌سازی شده است. تجربه و قابلیت‌های رابط React قبلی در ساختار Angular بازسازی می‌شوند؛ کدهای React اصلی در پوشه «پوشه فرانت سابق با React» محفوظ هستند.

## اجرا

```bash
npm install
npm start
```

Angular روی `http://localhost:4200` اجرا می‌شود. بک‌اند NestJS در پوشه `../back` و روی پورت ۳۰۰۱ اجرا می‌شود.

صفحه‌ی اصلی و فهرست نمونه‌ی پروژه‌ها در این مرحله پیاده‌سازی شده‌اند. ورود و ثبت‌نام تا زمان آماده‌شدن API احراز هویت نمایشی هستند.
